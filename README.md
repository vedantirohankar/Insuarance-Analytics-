# Insurance Analytics Dashboard

An interactive **Insurance Analytics Dashboard** designed to analyze policy performance, customer distribution, premium trends, and claim-related insights. This project transforms raw insurance data into meaningful business insights through data analysis and interactive visualizations.

## Project Overview

The Insurance Analytics project focuses on understanding insurance business performance by analyzing policy, customer, premium, and claims data.

The dashboard helps stakeholders monitor key performance indicators (KPIs), identify trends, compare business performance, and make data-driven decisions.

## Objectives

- Analyze the total number of customers and policies.
- Monitor total premium and coverage amounts.
- Evaluate insurance claims and claim amounts.
- Track premium growth over time.
- Understand customer demographics and age-group distribution.
- Identify policy status and active policy trends.
- Highlight top-performing insurance categories and business segments.

## Key Performance Indicators (KPIs)

The dashboard focuses on the following metrics:

- **Total Customers:** Overall number of customers in the dataset.
- **Total Policies:** Number of insurance policies issued.
- **Total Premium:** Total premium amount generated.
- **Total Coverage:** Overall insurance coverage amount.
- **Total Claims:** Number of claims recorded.
- **Total Claim Amount:** Financial value of claims.
- **Active Policies:** Number of currently active policies.
- **Premium Growth:** Changes in premium performance over time.

## Dashboard Insights

The dashboard provides insights into:

1. **Customer Analysis** – Understand customer distribution and demographics.
2. **Policy Analysis** – Evaluate policy issuance, status, and distribution.
3. **Premium Analysis** – Track premium performance and growth trends.
4. **Claims Analysis** – Analyze claim volumes and claim amounts.
5. **Age Group Analysis** – Compare customer distribution across age groups.
6. **Top Performers** – Identify leading categories based on premium or policy performance.

## Data Analysis Workflow

1. Import the insurance dataset.
2. Inspect the data and identify missing or inconsistent values.
3. Perform data cleaning and transformation using Power Query.
4. Create calculated measures using DAX.
5. Develop KPI cards, charts, and interactive visuals.
6. Apply filters and slicers for detailed analysis.
7. Interpret the dashboard results and derive business insights.
